# Current bifurcation figures

Use the [400 ms AVA/AVB handoff](../docs/ava_avb_handoff/README.md) for the current
focused bifurcation results and XPP model. All four primary figures were
regenerated together at tau_w = 400 ms; the beta diagram sweeps beta while the
command-drive diagrams hold beta = 1.03. The run manifest records parameters,
execution times, and file hashes.

Files explicitly suffixed `tau_w_410` are separate sensitivity comparisons.
Other historical figures in the repository are not necessarily at the canonical
parameters. In particular, the dense drive and hysteresis sweeps were not
regenerated by the focused handoff runner.
